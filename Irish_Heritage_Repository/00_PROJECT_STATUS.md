# Repository Vision

To build a carefully referenced, evidence-led body of knowledge concerning
Irish heritage by distinguishing clearly between primary sources,
historically supported evidence, mythology, language, and later
interpretation.

This repository grows one verified artifact at a time.

Build a repository that allows every future document to be:

- clearly sourced;
- independently reviewable;
- distinguishable from mythology, folklore, and modern interpretation where appropriate.
