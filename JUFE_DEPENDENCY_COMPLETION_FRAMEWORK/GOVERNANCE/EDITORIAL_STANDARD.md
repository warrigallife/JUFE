# JUFE Editorial Standard

**Version:** 0.1
**Status:** DRAFT

---

# 1. Purpose

This document defines the editorial standards governing all JUFE reference specifications.

These standards provide the basis for:

- specification consistency;
- automated linting;
- metadata extraction;
- dependency analysis;
- traceability analysis;
- future runtime implementation.

---

# 2. Chapter Structure

Every specification chapter shall contain, where applicable:

- Metadata
- Purpose
- Scope
- Normative Content
- Dependencies
- Conformance Requirements
- Verification Conditions
- Completion Status

Additional sections may be included where required by the specification.

---

# 3. Status Labels

Normative status labels are:

- EXPLICIT
- PROVISIONAL
- UNRESOLVED

These labels shall be used consistently throughout the specification.

---

# 4. Editorial Principles

The specification shall:

- distinguish manuscript content from engineering conventions;
- identify all unresolved material explicitly;
- avoid silent assumptions;
- avoid duplicated definitions where practical;
- preserve traceability to the source manuscript.

---

# 5. Evolution

This document evolves alongside the specification.

Whenever a recurring editorial pattern is discovered during review, it shall be added here before being adopted across the specification.
