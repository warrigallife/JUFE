# Manuscript Fidelity

- [ ] Has any new mechanism been introduced?

---

# Specification

- [ ] Does the specification organise rather than replace the manuscript?
- [ ] Are chapter boundaries clear?
- [ ] Are definitions referenced correctly?

---

# Engineering

- [ ] Constraints clearly separated from manuscript statements.

# Repository

- [ ] References updated.
