# JUFE Repository Specification

Welcome to the JUFE Repository.

This repository contains the complete development ecosystem of the JUFE framework.

Rather than representing a single document, the repository is organised as a collection of interdependent architectural layers, each with a distinct responsibility within the overall framework.

The Repository Specification serves as the architectural guide to that ecosystem.

It explains how the repository is organised, how knowledge progresses through the project, how research informs formal specification, how specifications guide runtime implementation, and how every component contributes to the long-term evolution of JUFE.

Before exploring the mathematical specifications, research manuscripts, or runtime implementation, contributors are encouraged to become familiar with the repository architecture described here.
