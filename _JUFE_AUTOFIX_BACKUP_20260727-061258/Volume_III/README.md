# Volume III – Local Field Mechanics

## Overview

Volume III is the normative specification for the local field mechanics of the
JUFE / ABTM computational framework.

It formalises the concepts introduced in the manuscript *Relational Unified
Field Mechanics* by Thomas F. Jennings into a structured technical
specification suitable for implementation, verification, and future
development.

## Document Authority

The normative authority for Volume III is the manuscript
*Relational Unified Field Mechanics* by Thomas F. Jennings.

The governing document for this specification is:

- `00-Normative-Traceability-Matrix.md`

## Repository Structure

This directory contains the normative specification for Volume III.

- `README.md` provides an overview of the volume.
- `00-Normative-Traceability-Matrix.md` defines the governing editorial and traceability rules.
- The chapter files contain the normative technical specification.

## Scope

This volume specifies local field mechanics, gradient behaviour, phase-lock
mechanics, information preservation, global equilibrium, and the unified ABTM
field equations.

Implementation details belong within the runtime and engine layers and are therefore outside the scope of the normative manuscript.
