## Preservation

All 26 destination files use their original Git blobs. No heading stripping,
line wrapping, extraction or splitting is applied. Existing descriptive
filenames are retained where already established; the file contents are unchanged.

`CANONICAL/` contains 18 retained source artifacts, including the whole `11.md`
and V4 architecture. Inclusion is source preservation, not mathematical or
empirical validation, classification approval or runtime implementation.

`MISSING_SOURCE/4.md`, `5.md`, `16.md`, and `34.md` preserve the supplied
label/body variants and title-only material without reconstructing content.
The existing Pt.3 placeholder is an explanatory record, not an additional
source manuscript. Pt.3's complete body remains unavailable. The Pt.2,
Vacuum Mass Gap and a tri Ω=smoke label/body questions remain unresolved.

The complete combined manuscript is in `Research Processing/`; its former
Manuscript 001/002 split source copies are removed. Existing analysis in those
folders and processed documents in `Specifications/Research Archive/` remain
separate derived material and must not substitute for the original source.

V4/source `36.md` is preserved once at its existing named CANONICAL path;
the duplicate template copy is removed without interpreting its contents.

No mathematics, definition identifiers, specifications or runtime logic were
changed by this source update.
