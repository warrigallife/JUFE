# Start here

This branch (`collab/needs-from-liam`) was made for you. Nothing on `main` has been
changed, and nothing here can change JUFE's meaning. It is a way to send us the few
things we need, so the work can go on.

You do not need to use Git. Everything below works in the GitHub web page.

## What we did

We worked in a separate copy of your repositories and did not edit `main`:

- Fixed one problem that stops JUFE from starting on Linux (`src/runtime.py`).
- Wrote 34 tests that record what the code does today.
- Mapped every launcher in `docs/LAUNCHER_MAP.md`.
- Wrote down what we found, and what we did *not* touch, in
  `docs/COLLABORATOR_MESSAGE.md` and `docs/agents/AGENT_WORKFLOW.md`.

We did not change the specification, the parser, any status wording, or any of the
mathematics. Those are yours (and Tom's) to decide.

## What we need from you — three short steps

### Step 1. Answer the questions (the main one)

1. Open **`ANSWERS.md`** on this branch.
2. Click the **pencil icon** (top right of the file) to edit.
3. Tick a box by typing an `x` between the brackets, like `[x]`, or type your answer
   under the question. "Not sure" is a fine answer.
4. Click **Commit changes**. Choose **Commit directly to the
   `collab/needs-from-liam` branch**, then confirm.

### Step 2. Upload the three files that only exist on your Mac

These were never uploaded, so we cannot see them:

- `jufe_explorer.py`
- `Start JUFE Explorer.command`
- `JUFE Explorer - READ ME.txt`

If your copy of `Specifications/SPEC-010.md` differs from the one on GitHub, upload it
too (see question 1).

1. Open the **`incoming`** folder on this branch.
2. Click **Add file → Upload files**.
3. Drag the files in, then click **Commit changes**, again choosing **Commit directly
   to the `collab/needs-from-liam` branch**.

Please upload copies only. Do not delete or rename anything in your own folder.

### Step 3. Tell us you are done

Send a short message ("done"). Then we pick up from your answers.
